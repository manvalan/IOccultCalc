🚀 QUICK START
--------------------------------------------------------------------------------

1. SETUP DIPENDENZE
   $ git submodule add https://github.com/manvalan/IOC_StarMap external/IOC_StarMap
   $ # Aggiorna CMakeLists.txt (vedi IOC_STARMAP_CODE_UPDATE.sh)

2. COMPILA ESEMPIO
   $ ./build.sh
   $ ./build/examples/italoccult_starmap_example

3. VERIFICA OUTPUT
   $ cat example_starmap_italoccult.html | grep -c '<svg'
   # Output: 2 (approach + final chart)

4. GENERA PDF
   $ python3 convert_to_pdf.py example_starmap_italoccult.html
   $ open example_starmap_italoccult.pdf

5. INTEGRA IN ITALOCCULTFORMATTER
   # Segui: IOC_STARMAP_INTEGRATION.md
   # Script: IOC_STARMAP_CODE_UPDATE.sh
